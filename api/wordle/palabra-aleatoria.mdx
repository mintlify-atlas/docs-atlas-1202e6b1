Returns a random Spanish word from the `diccionario.palabras` table that has exactly `numLetras` letters. This is the primary endpoint used to generate the target word at the start of each Wordle game session. No authentication is required.

## Endpoint

`GET /wordle/palabra/{numLetras}` — no authentication required.

## Path Parameters

<ParamField path="numLetras" type="integer" required>
  The exact number of letters the returned word must have. Practical game values are **5–8**; the API supports any word length present in the database.
</ParamField>

## Example Request

```bash
curl http://localhost:8080/wordle/palabra/5
```

## Response

Returns a `PalabraDTO` object.

<ResponseField name="id" type="integer">
  The database row ID of the word in `diccionario.palabras`.
</ResponseField>

<ResponseField name="palabra" type="string">
  The randomly selected Spanish word. Always contains the `sin_acentos` variant — accent marks are stripped.
</ResponseField>

### Example Response

```json
{
  "id": 42,
  "palabra": "gatos"
}
```

<Note>
  The `palabra` field always contains the `sin_acentos` variant of the word. Accent marks (tildes, etc.) are removed before storage, so the value returned will never include characters like `á`, `é`, `í`, `ó`, or `ú`.
</Note>

<Note>
  Randomisation is performed using a `floor(random() * max(id))` SQL approach for query performance. As a side effect, if no word exists in the database with the requested length, the query may return an unexpected result or error. Ensure the dictionary is seeded with words of the desired length before calling this endpoint.
</Note>

## Practical Notes

The standard Wordle game mode fetches **5-letter words** (`numLetras=5`). The API is not restricted to this value — you may request words of any length that is represented in the database (typically 5–8 characters after the bulk import). Choose the length that matches your intended game difficulty.
