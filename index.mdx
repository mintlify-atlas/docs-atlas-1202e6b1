Wordle Backend is a production-ready Spring Boot 3 REST API that powers a Spanish-language Wordle game. It provides endpoints for fetching random words by length, validating guesses against a 57,000+ word dictionary, managing authenticated user accounts, and returning a live top-3 leaderboard. The service is stateless, secured with JWT, and deployable to any container host or PaaS with a single Docker command.

## How it works

<Steps>
  <Step title="Register or log in">
    Call `POST /auth/registro` to create an account, or `POST /auth/login` to receive a JWT token. The token is valid for 3 hours.
  </Step>
  <Step title="Fetch a word">
    Call `GET /wordle/palabra/{numLetras}` with the desired word length (5–8 letters) to receive a random Spanish word from the dictionary.
  </Step>
  <Step title="Validate guesses">
    After each player guess, call `GET /wordle/palabraExiste/{palabra}` to confirm the guessed word is in the dictionary before scoring it.
  </Step>
  <Step title="Submit a score">
    When the game ends, call `PUT /usuario/sumarPuntos/{puntos}` with your JWT token in the `Authorization` header to add points to the authenticated player's total.
  </Step>
</Steps>

<Note>
  All endpoints under `/auth/**` and most read endpoints are open. Only score-write operations (`PUT /usuario/sumarPuntos`) require a valid JWT token.
</Note>
