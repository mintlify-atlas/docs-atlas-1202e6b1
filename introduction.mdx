Wordle Backend is a production-ready REST API that powers a Spanish-language Wordle game. Built on **Spring Boot 3.4.3** and **Java 21**, it handles everything from user authentication and session management to word validation, guess scoring, and leaderboard tracking — giving front-end clients a clean, stateless HTTP interface to build on.

## What the API Does

The API serves three core audiences:

- **Game clients** (web or mobile) that need a daily or random Spanish word, want to validate guesses, and need to display a live leaderboard.
- **Authenticated players** who register, log in, and track personal statistics across sessions.
- **Administrators and developers** who want a self-hostable, containerisable backend they can extend or deploy to a cloud platform like Render in minutes.

## Architecture Overview

The application is organised around three controller groups, a JWT security filter, and a JPA persistence layer:

```
┌─────────────────────────────────────────────────────────┐
│                        HTTP Clients                      │
└───────────────────────────┬─────────────────────────────┘
                            │
              ┌─────────────▼──────────────┐
              │      JWT Auth Filter        │
              │  (validates Bearer tokens)  │
              └─────────────┬──────────────┘
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
┌───────▼───────┐  ┌────────▼───────┐  ┌───────▼────────┐
│  Auth          │  │  Wordle        │  │  User          │
│  Controller   │  │  Controller    │  │  Controller    │
│  /auth/**     │  │  /wordle/**    │  │  /usuario/**   │
└───────┬───────┘  └────────┬───────┘  └───────┬────────┘
        │                   │                   │
        └───────────────────┼───────────────────┘
                            │
              ┌─────────────▼──────────────┐
              │      JPA Repositories       │
              │  (Spring Data / Hibernate)  │
              └─────────────┬──────────────┘
                            │
              ┌─────────────▼──────────────┐
              │         PostgreSQL          │
              └─────────────────────────────┘
```

- **Auth controllers** (`/auth/**`) handle registration and login, issuing signed JWT tokens on success.
- **Wordle controllers** (`/wordle/**`) expose word retrieval, guess validation, and leaderboard endpoints. Most routes are protected and require a valid token.
- **User controllers** (`/usuario/**`) let authenticated players query and update their own profile and statistics.
- **JWT filter** intercepts every request, extracts the `Authorization: Bearer <token>` header, validates the signature, and populates the Spring Security context before the request reaches any controller.
- **JPA repositories** abstract all database access. Entities are mapped with Hibernate and projected with MapStruct DTOs to keep the API surface clean.

<Note>
  All words in the dictionary — and all game logic — are in **Spanish**. Guess validation, word length filtering, and Ignatian mode all operate exclusively on Spanish vocabulary. Clients should present the UI in Spanish or provide their own translation layer.
</Note>
